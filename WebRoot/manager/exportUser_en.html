Exports all users matching the current search condition (not only the current page).
Columns: User ID, User Name, Real Name, Nick Name, Mobile, Email, Role, Create Type, Create Time, Last Login Time, Last Login IP, Last Login City, Network Settings, Intro.
CSV: comma separated (UTF-8 with BOM) for scripting; Excel: mobile/ID are stored as text so Excel will not turn them into scientific notation.
The exported file can be imported directly by "Import".
