Required when the servers belong to different domains, and must be unique; log in with "domain/account".

Search base for users (users cannot be found without it).
Almost every LDAP / AD server uses simple.
Attribute matched against the login name: OpenLDAP uses uid, AD uses sAMAccountName (empty = uid).
Account (DN form) used to look up the user DN. Empty = authenticate as the logging-in user.
Password of the bind account (stored in clear text in the system configuration).
Only "domain/account" is accepted for this server, so same-named accounts in different domains cannot collide.
