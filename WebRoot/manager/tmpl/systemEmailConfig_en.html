Parameter Value
Email Service Current provider: {{value.providerName}}. When disabled, registration codes, password reset and share notifications are not sent.
Provider
From address The address recipients see. Leave empty to use the SMTP account below (most providers require them to match).
Sender name Optional display name; when empty only the address is shown.
SMTP server Use the smtp host given by your mail provider (e.g. smtp.qiye.aliyun.com, smtp.163.com).
Port Must match the encryption: none 25, STARTTLS 587, SSL/TLS 465. 0 or empty means the default port of the selected encryption. Cloud hosts usually block outbound port 25, so 587/465 is required there.
Encryption
Account
Password / auth code 163, QQ and most corporate mailboxes require an auth code (generated after enabling SMTP in the mailbox settings), not the login password.
Authentication Required by almost every provider; only internal relays may turn it off.
Trust any certificate Equivalent to mail.smtp.ssl.trust=*. Do not enable it for public mail servers.
Content type Keep text/html;charset=UTF-8. The legacy gb2312 value was converted to UTF-8 during the one-time migration (otherwise non-ASCII text breaks).
Connect timeout (ms) Maximum time to establish the connection (1000~60000).
Read timeout (ms) Maximum time to wait for the server response (1000~300000). A smaller value makes "port blocked" fail fast instead of hanging.
While editing, the values currently on the page are used (try before saving); in read-only mode the saved configuration is used. The mail configuration is stored in the database (mail.* rows of system_setting). The old values in docSysConfig.properties are only the defaults for the first-time migration - editing them has no effect afterwards.
