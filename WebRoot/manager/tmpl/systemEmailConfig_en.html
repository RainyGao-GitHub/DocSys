Parameter Value
Email Service Current provider: {{value.providerName}}. When disabled, registration codes, password reset and share notifications are not sent.
Provider
From address The address recipients see. Leave empty to use the SMTP account below (most providers require them to match).
Sender name Optional display name; when empty only the address is shown.
SMTP server Use the smtp host given by your mail provider (e.g. smtp.qiye.aliyun.com, smtp.163.com).
Port Must match the encryption: none 25, STARTTLS 587, SSL/TLS 465. 0 or empty means the default port of the selected encryption. Cloud hosts usually block outbound port 25, so 587/465 is required there.
Encryption
Account
Password / auth code 163, QQ and most corporate mailboxes require an auth code (generated after enabling SMTP in the mailbox settings), not the login password.
Authentication Required by almost every provider; only internal relays may turn it off.
Trust any certificate Equivalent to mail.smtp.ssl.trust=*. Do not enable it for public mail servers.
TLS protocols Space separated. Keep TLSv1.2: without this value JavaMail starts a TLSv1 (TLS 1.0) handshake and modern mail servers (e.g. NetEase enterprise mail) reject it, which surfaces as "Could not convert socket to TLS". Do not list a protocol your JDK does not support (such as TLSv1.3 on JDK 8) or the setting fails with an argument error.
AccessKeyId Create it in Alibaba Cloud Console → Access Control → AccessKey. A RAM sub-account limited to DirectMail is recommended.
AccessKeySecret Used together with the AccessKeyId; never written to logs.
Sender address An address created and verified under DirectMail "Sender addresses". It also becomes the From address of the mail.
Region Recorded only: the send API itself takes no region parameter.
Endpoint Leave empty to use {{value.providerDefaults.aliyun}}. Note: this API does not support attachments — mails with attachments fail with an explicit error; use SMTP or Tencent SES instead.
SecretId Tencent Cloud Console → Access Management → API Keys.
SecretKey
Region Required; this API only supports ap-guangzhou and ap-hongkong.
Sender address Created under "Sender addresses" in the console; the sending domain must pass SPF/DKIM verification first. Leave empty to fall back to "From address" above.
Endpoint Leave empty to use {{value.providerDefaults.tencent}}.
Content mode Tencent marks "custom content" as deprecated: new accounts must enable that permission first, otherwise the API rejects the call (code 1011). In template mode the body comes from the console template and this system only passes short variables (official limit: 800 bytes, no HTML).
Template ID Template mode only: the numeric ID of an approved console template.
Variable names Subject: Body: Refer to your template for the placeholder syntax; empty means subject / content.
Gateway URL Must start with http:// or https://.
HTTP method
Body format
Parameter names To: Subject:
Body: From: Empty means the default name shown in the placeholder; change it to match your gateway.
Fixed parameters One name=value per line; sent with every request (e.g. a gateway apikey).
Success check Field: Expected: The send counts as successful only when that JSON field equals the expected value; leave it empty to rely on HTTP 2xx only (some gateways return 200 for business failures).
Content type Keep text/html;charset=UTF-8. The legacy gb2312 value was converted to UTF-8 during the one-time migration (otherwise non-ASCII text breaks).
Connect timeout (ms) Maximum time to establish the connection (1000~60000).
Read timeout (ms) Maximum time to wait for the server response (1000~300000). A smaller value makes "port blocked" fail fast instead of hanging.
While editing, the values currently on the page are used (try before saving); in read-only mode the saved configuration is used. The old values in docSysConfig.properties are only the defaults for the first-time migration - editing them has no effect afterwards.
