参数 配置值
邮件服务 当前发信方式：{{value.providerName}}；关闭后注册验证码、找回密码、文件分享通知等邮件都不会发送。
发信方式
发件人邮箱 收件人看到的发件地址；留空则使用下面的 SMTP 登录账号。多数邮箱要求它与登录账号一致。
发件人显示名 可选；留空则只显示邮箱地址。
SMTP 服务器 企业/自建邮箱填服务商给的 smtp 地址（如 smtp.qiye.aliyun.com、smtp.163.com）。
端口 与加密方式配套：不加密 25、STARTTLS 587、SSL/TLS 465；填 0 或留空按所选加密方式的默认端口。云主机通常封禁出站 25 端口，那时必须改用 587/465。
加密方式
登录账号
登录密码/授权码 163、QQ、企业邮箱等必须填授权码（在邮箱后台开启 SMTP 服务后生成），不是登录密码。
需要认证 绝大多数服务商都要求开启；只有内网中继才可能关闭。
信任任意证书 勾选后等同 mail.smtp.ssl.trust=*；公网邮箱请勿勾选。
AccessKeyId 阿里云控制台 → 访问控制 → AccessKey 创建；建议用 RAM 子账号并只授予「邮件推送」权限。
AccessKeySecret 只与 AccessKeyId 成对使用；不会回显到日志里。
发信地址 邮件推送控制台「发信地址」里创建并完成验证的地址；它同时就是邮件里的发件人。
地域 仅作记录：发信接口本身不带地域参数。
接入地址 留空用默认 {{value.providerDefaults.aliyun}}。⚠️ 该接口不支持附件：带附件的邮件会被直接报错，请改用 SMTP 或腾讯云 SES。
SecretId 腾讯云控制台 → 访问管理 → API 密钥。
SecretKey
地域 必填；该接口只支持 ap-guangzhou 与 ap-hongkong。
发信地址 控制台「发信地址」里创建；发信域名需先完成 SPF/DKIM 验证。留空则用上面的「发件人邮箱」。
接入地址 留空用默认 {{value.providerDefaults.tencent}}。
内容模式 腾讯云已把「自定义内容」标为废弃：新账号需先开通该权限才能用第一种，否则会被拒（返回码 1011）。模板模式的正文来自控制台模板，本系统只传短变量（官方限制 ≤800 字节且不能是 HTML）。
模板 ID 仅模板模式需要：控制台建好模板并通过审核后的数字 ID。
模板变量名 主题变量： 正文变量： 控制台模板里引用这两个变量的写法以模板自身的说明为准；留空则用 subject / content。
网关地址 需以 http:// 或 https:// 开头。
请求方法
请求体格式
参数名映射 收件人： 主题：
正文： 发件人： 留空则用括号里的默认参数名，按网关要求改。
固定参数 每行一个 参数名=值，每次请求都会带上（如网关的 apikey）。
成功判定 响应字段： 期待值： 响应 JSON 里该字段等于期待值才算发送成功；留空则只按 HTTP 2xx 判定（部分网关 200 也可能是业务失败）。
正文类型 建议保持 text/html;charset=UTF-8；老配置里的 gb2312 已在首次迁移时改成 UTF-8（否则中文会乱码）。
连接超时(毫秒) 与服务器建立连接的最长等待（1000~60000）。
读取超时(毫秒) 等待服务器投递结果的最长等待（1000~300000）。调小可让「端口被封」这类问题更快报错，而不是一直转圈。
